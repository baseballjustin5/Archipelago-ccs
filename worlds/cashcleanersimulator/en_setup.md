## Windows Cash Cleaner Mod Setup


### Cash Cleaner Mod Support set up

1. Backup vanilla Cash Cleaner Sim (CCS) Saves
	* Save locations
    * Windows:
        * `C:\Users\<username>\AppData\Local\CashCleanerSimulator`
          * You can use `%localappdata%` in your File Explorer to get directly to `\appdata\local\` then go to the `CashCleanerSimulator` folder.
          * The `CashCleanerSimulator\Saved` folder has everything in your game, both game saves, as well as game configs like visual, control, and audio settings.

2. Download UE4SS Experimental-Latest: (CCS uses Unreal Engine Version 5.4) 
  * As of July 2nd, 2026 0600 CDT
  * https://github.com/UE4SS-RE/RE-UE4SS/releases/download/experimental-latest/UE4SS_v3.0.1-1003-g01dd8052.zip

3. Extract the UE4SS_v3.0.1 zip to your Cash Cleaner Install folder, where the `CashCleanerSim-Win64-Shipping.exe` is located.

  * Right click the game name in the Steam library list (or the cog on the steam library page itself)
    * Mange > Browse Local Files
    <img width="2752" height="900" alt="CashCleanerSim_BrowseLocalFiles" src="https://github.com/user-attachments/assets/5e934acc-b7a4-4448-9c74-4a1a1101f113" />
    <img width="962" height="1070" alt="CashCleanerSim_BrowseLocalFiles_RC" src="https://github.com/user-attachments/assets/1b13afbe-23d8-4a86-ae1f-a6c51b8fb84a" />
    * Then go into CashCleanerSimulator > Binaries > Win64
      * Default is `C:\Program Files (x86)\Steam\steamapps\common\Cash Cleaner Simulator\CashCleanerSimulator\Binaries\Win64`
      * Folder structure will look like this:
        * Binaries
          * Win64
            * ue4ss
              * Mods

### Cash Cleaner is now set up for mods:
> Installing the mod files


1. Download [Randomizer.zip](https://github.com/aymeric-duchein/Cash-cleaner-randomizer/releases/download/Archipelago-0.0.1/Randomizer.zip)
2. Extract to the UE4SS mods folder; 
  * It will look like
    * ue4ss
      * Mods
        * Randomizer
          * Saved
          * Scripts
3. Edit `enabled.txt` with the text:
   
   1
   
   then save and exit

### Archipelago world set up

1. Download the .AP world to your archipelago install's custom-worlds folder
    * [ccs.apworld](https://github.com/aymeric-duchein/Archipelago-ccs/releases/download/0.0.1/ccs.apworld)
    * Default location:
      * `C:\ProgramData\Archipelago\custom_worlds`
2. Generate a new game via Archipelago Launcher > Generate
3. An archive named `<player_name>_ccs_ap_config.zip` is generated for each CCS player in the output folder.
4. Extract it into the Saved folder of the Randomizer mod. 
	* It will look like this:  
		* Mods
			* Randomizer  
				*	Saved  
					*	ap_config.lua
5. Fill out the ap_config.lua with your server settings:

```lua
return {
  -- AP Server connection; localhost if local (same computer), IP_Address:port if another device - 192.168.1.1:38281 for example
  host = "<either 'localhost:Port' or 'IP_Address:Port' for connection to hosting AP server>",

  player = "<player name used in yaml>",

  -- This is set by the person who generated the AP World, they will give this to you. 
  password = "<whatever password is set by the Host of the AP World, blank if none>",

  -- DO NOT CHANGE THIS, THIS IS GENERATED BY THE ARCHIPELAGO SERVER GENERATION
  seed = <provided game seed>,
}
``` 

An example Locally hosted AP server ap_config.lua:

```lua
return {
  host = "localhost:38281",
  player = "CCS",
  password = "",
  seed = 27539597866641992464,
}
```

### Between two separate Archipelago games: 
Make sure to remove the `ap_config.lua` and `state.lua` from the Saved folder or the new rando settings will not work.
